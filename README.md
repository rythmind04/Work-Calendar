# Смены

Веб-приложение для сменных графиков. Откройте календарь, нажмите **Новый график**, укажите имя, цикл 2/2, 3/3 или 4/4 и первый день рабочего блока. Добавьте второй график, выберите человека в разделе **Общие выходные** и нажмите **Показать даты**. Совпадения отмечаются янтарным цветом и отображаются списком под календарём.

Нажатие на дату меняет статус смены на этот день. График начинается с указанной даты. Более ранние дни считаются неизвестными, пока статус не задан вручную. Изменение цикла или даты начала пересчитывает автоматические дни и сохраняет ручные правки.

## Публикация на GitHub Pages

1. Распакуйте архив. Загрузите всё содержимое архива в корень репозитория на GitHub в ветку **main**, включая папку **icons**. На одном уровне должны лежать **index.html**, **sw.js** и **manifest.webmanifest**.
2. Откройте **Settings → Pages**. Выберите **Deploy from a branch**, затем **main → /(root)** и нажмите **Save**.
3. Когда GitHub Pages опубликует приложение, откройте HTTPS-ссылку из раздела **Settings → Pages**.

## Установка на iPhone

Откройте опубликованную ссылку в Safari. Нажмите **Поделиться → На экран «Домой»**, включите **Открыть как веб-приложение**, если этот переключатель есть, и нажмите **Добавить**. Запустите приложение с иконки с подключённым интернетом. Когда появится надпись **Доступно офлайн**, календарём можно пользоваться без сети.

Графики хранятся в браузере или установленном веб-приложении на устройстве. Они не синхронизируются между устройствами. Для хранения расписания на iPhone добавляйте графики после первого запуска с иконки.

## Локальная проверка

Из папки приложения запустите локальный HTTP-сервер, например командой `python -m http.server 8000`, и откройте `http://localhost:8000/`. Офлайн-режим требует HTTPS либо localhost. При изменении файлов в будущих версиях обновите номер кэша в **sw.js**, чтобы устройства получили обновление.
